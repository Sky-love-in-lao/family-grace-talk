# 🏡 우리가족 은혜톡 (Family Grace Talk)

**우리가족 은혜톡**은 온 가족이 함께 매일 성경을 읽고 은혜를 나누며, 주간 가정예배를 드릴 수 있도록 돕는 가족 맞춤형 웹 애플리케이션(PWA)입니다.

## ✨ 주요 기능

### 1. 📖 맥체인 기반 1년 1독 성경읽기 (부모님 & 아이들 맞춤형)
- 매일 4장의 맥체인 성경읽기 진도표가 제공되어 **부모님은 1년 동안 성경 전체를 1독**하실 수 있습니다.
- **아이들 자동 맞춤 배정:** 4장의 본문 중 아이들이 읽기 가장 좋은 **신약 1장(복음서 > 서신서 > 예언서 우선순위)**을 앱이 스스로 판단하여 아이들의 오늘의 말씀으로 자동 배정합니다.

### 2. 💡 어린이 눈높이 맞춤 해설 (QT)
- 아이들이 배정받은 신약 말씀에 대해, 7~9세 아이들의 눈높이에 맞춘 **친절하고 상세한 묵상 해설**이 제공됩니다.
- 성경의 어려운 단어(구원, 성령님, 호적 등)를 아이들이 이해하기 쉽게 괄호로 풀어서 설명하며, 그날의 말씀을 삶에 적용할 수 있는 질문을 제공합니다.

### 3. ✅ 실시간 읽기 체크 동기화 (Firebase)
- 각자 스마트폰이나 태블릿에서 '오늘 말씀 다 읽었어요!' 버튼을 누르면, **다른 가족들의 기기에도 실시간으로 초록색 체크(✔) 마크가 동기화**됩니다.
- 멀리 떨어져 있거나 각자의 방에 있어도 서로의 말씀 읽기 현황을 실시간으로 응원할 수 있습니다.

### 4. 💬 가족 나눔방 (실시간 채팅)
- 말씀 묵상 후 받은 은혜나 기도 제목을 나눌 수 있는 **가족 전용 실시간 채팅방**입니다.
- 카카오톡처럼 실시간으로 메시지가 공유되어 가족 간의 영적 소통을 돕습니다.

### 5. ⛪️ 가정예배 가이드
- 수요일, 금요일(또는 원하는 요일) 가족이 모여 예배드릴 수 있도록 **가정예배 순서지(신앙고백, 찬양, 대표기도, 주기도문 등)** 화면을 제공합니다.
